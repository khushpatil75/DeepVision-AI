Project Methodology

Developed from scratch, this system utilizes a parallel-inference pipeline to evaluate hand-drawn data against three distinct deep learning paradigms simultaneously.

📊 Dataset Engineering

  • DHCD (Hindi): Trained on 46 distinct classes mapping complex consonants and numerical digits of the Devanagari script.
  • EMNIST (English): Utilized the 'Balanced' split (47 classes) covering uppercase, lowercase, and numeric datasets.
  • Sanskrit (Custom): Expanded linguistic capabilities with 19 distinct ancient Sanskrit conjuncts (Jodakshara).
  • Preprocessing: Dynamic color-inversion pipelines flawlessly interpret white-canvas user inputs and real-world photographs for black-background models.

🧠 Neural Architectures

  • Deep CNN: Custom multi-layer convolutional network utilizing Batch Normalization and Dropout for robust feature extraction.
  • Vision Transformer: Divided image into 16x16 patches using self-attention to understand global character structures.
  • Hybrid Model: State-of-the-art approach fusing a ResNet18 backbone with a multi-layer Transformer Encoder.

⚙️ Training & Deployment

  • Hardware: Models were compiled and trained using GPU acceleration for high-dimensional tensor operations.
  • Optimization: Network weights optimized using Adam optimizer alongside Cross-Entropy Loss over extended epoch cycles.
  • API Backend: Deployed via a custom, asynchronous FastAPI backend running PyTorch in inference mode for real-time Softmax probability scoring.
